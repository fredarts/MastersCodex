## 💡 Dicas para Capturas Perfeitas

1. **Tema Escuro & Alta Definição**: Use o tema padrão com alto contraste para valorizar as cores douradas e o tom de fantasia medieval.
2. **Resolução**: Recomendamos capturas em Full HD (`1920x1080`) para telas desktop e `1080x2400` para capturas em smartphones.
3. **Formato**: Utilize `.png` para imagens com detalhes nítidos de texto e UI ou `.webp` de alta qualidade.
4. **Modo Fullscreen**: Pressione `F11` no navegador antes de capturar a tela para ocultar barras de navegação e abas do browser.
